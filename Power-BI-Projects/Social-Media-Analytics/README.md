# 📊 Social Media Analytics Dashboard

## 📌 Project Overview

An interactive **Power BI Social Media Analytics Dashboard** developed to monitor and analyze social media performance across **Facebook, Instagram, LinkedIn, and X**.

The dashboard provides insights into audience engagement, impressions, audience growth, and response rates while enabling comparison between different social media platforms over time.

---

## 🎯 Business Objective

The main objective of this project was to provide a centralized view of social media performance and help identify engagement and audience growth patterns across different platforms.

The analysis focuses on:

* Monitoring social media performance
* Analyzing impressions and reach
* Measuring audience engagement
* Tracking audience growth
* Analyzing response rates
* Comparing performance across platforms
* Monitoring weekly performance trends

## 🔍 Analysis Performed

### Impressions Analysis

Analyzed impressions generated across different social media platforms to understand content visibility and overall reach.

### Engagement Analysis

Analyzed audience engagement to identify how users interact with content across different platforms.

### Audience Growth

Monitored audience growth over time to understand changes in the social media audience.

### Response Rate Analysis

Analyzed response rates to evaluate how effectively social media platforms respond to audience interactions.

### Platform Comparison

Compared Facebook, Instagram, LinkedIn, and X to identify differences in social media performance.

### Weekly Performance

Analyzed weekly trends to monitor changes in impressions, engagement, audience growth, and response rates over time.
