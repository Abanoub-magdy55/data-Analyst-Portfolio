# 📊 Project Management Dashboard

## 📌 Project Overview

An interactive **Power BI Project Management Dashboard** developed to analyze project performance, cost reduction, income generation, and project benefits across different regions and project phases.

The dashboard provides a centralized view of project-related KPIs and enables users to analyze project performance through interactive visualizations and filters.

---

## 🎯 Business Objective

The main objective of this project was to develop an interactive dashboard that provides clear insights into project performance and financial impact.

The analysis focuses on:

* Monitoring project performance
* Analyzing cost reduction
* Tracking income generation
* Measuring project benefits
* Comparing regional performance
* Analyzing project phases
* Evaluating yearly cost-benefit performance

## 🔍 Analysis Performed

### Project Performance

Analyzed project performance using key project-related KPIs and performance indicators.

### Cost Reduction Analysis

Analyzed the amount of cost reduction generated by projects and evaluated cost-saving performance.

### Income Generation

Analyzed income generated through projects and compared financial performance across different areas.

### Project Benefits

Evaluated the benefits generated by projects to provide a clearer understanding of their financial impact.

### Regional Analysis

Compared project performance and financial metrics across different regions.

### Project Phase Analysis

Analyzed project performance across different project phases to identify differences in costs, benefits, and outcomes.

### Yearly Cost-Benefit Analysis

Compared project costs and benefits across different years to identify changes in financial performance over time.
