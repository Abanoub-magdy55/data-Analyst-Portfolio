# 📊 Vrinda Store Dashboard

## 📌 Project Overview

An interactive **Excel Vrinda Store Dashboard** developed to analyze sales trends, customer demographics, product categories, regional performance, and order fulfillment.

The dashboard transforms raw sales data into meaningful business insights and provides an interactive view of sales and customer performance.

---

## 🎯 Business Objective

The main objective of this project was to analyze Vrinda Store sales data and provide a clear overview of business performance and customer behavior.

The analysis focuses on:

* Monitoring sales trends
* Analyzing customer demographics
* Evaluating product category performance
* Comparing regional sales performance
* Analyzing order fulfillment
* Understanding customer purchasing patterns
* Providing an interactive reporting experience

## 🔍 Analysis Performed

### Sales Trend Analysis

Analyzed sales trends over time to understand changes in revenue and order performance.

### Customer Demographics

Analyzed customer demographics to understand purchasing behavior across different customer segments.

### Product Category Analysis

Compared sales performance across different product categories to identify high-performing categories.

### Regional Performance

Analyzed sales across different states and regions to identify areas with stronger sales performance.

### Order Fulfillment

Analyzed order statuses to understand order fulfillment and delivery performance.

### Customer Purchasing Analysis

Analyzed customer purchasing patterns to identify trends and understand customer behavior.

### Interactive Dashboard

Created an interactive Excel dashboard using visualizations and filters to allow users to explore sales and customer data from different perspectives.
