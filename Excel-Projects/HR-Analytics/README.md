# 📊 Human Resources Analytics Dashboard

## 📌 Project Overview

An interactive **Excel Human Resources Analytics Dashboard** developed to analyze workforce distribution, employee salaries, training hours, and employee performance.

The dashboard transforms HR data into meaningful insights that help provide a clear overview of workforce characteristics and employee performance.

---

## 🎯 Business Objective

The main objective of this project was to analyze workforce data and provide an interactive dashboard for monitoring key HR metrics.

The analysis focuses on:

* Analyzing workforce distribution
* Monitoring employee salaries
* Analyzing training hours
* Evaluating employee performance
* Understanding workforce characteristics
* Comparing employee performance across different areas
* Providing an interactive HR reporting experience

## 🔍 Analysis Performed

### Workforce Distribution

Analyzed employee distribution across different workforce categories to understand the overall composition of the organization.

### Salary Analysis

Analyzed employee salaries to understand salary distribution and compare compensation across different employee groups.

### Training Analysis

Analyzed training hours to evaluate employee development and training participation.

### Employee Performance

Analyzed employee performance to identify performance patterns and compare results across different employee groups.

### HR Analysis

Combined workforce, salary, training, and performance data to provide a comprehensive view of employee-related metrics.

### Interactive Dashboard

Created an interactive Excel dashboard using visualizations and filters to allow users to explore HR data from different perspectives.
