# 💳 Digital Wallet Transaction Dashboard

## 📊 Project Overview

An interactive Excel dashboard developed to analyze digital wallet transactions and provide insights into transaction performance, revenue, payment categories, device usage, and transaction success rates.

## 🎯 Business Objective

The objective of this project was to transform raw digital wallet transaction data into an interactive dashboard that helps stakeholders understand transaction behavior, identify performance trends, and monitor key business metrics.

## 🛠️ Tools Used

* Microsoft Excel
* Power Query
* Pivot Tables
* Pivot Charts
* Data Cleaning & Transformation
* Data Visualization
* KPI Analysis

## 📌 Key KPIs

* Total Transactions
* Total Revenue
* Successful Transactions
* Failed Transactions
* Transaction Success Rate
* Average Transaction Value

## 🔍 Analysis Performed

* Analyzed overall digital wallet transaction performance.
* Evaluated revenue generated from transactions.
* Compared transaction performance across different payment categories.
* Analyzed device usage and transaction behavior.
* Compared successful and failed transactions.
* Identified transaction trends and patterns.
* Developed interactive visualizations to support business analysis.

**Excel | Power Query | Pivot Tables | Data Visualization | KPI Development | Data Cleaning | Business Analysis | Dashboard Development**
