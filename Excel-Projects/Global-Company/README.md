# 📊 Global Company Dashboard

## 📌 Project Overview

An interactive **Excel Global Company Logistics Dashboard** developed to analyze shipping performance, delivery metrics, and logistics costs across multiple countries.

The dashboard transforms raw logistics data into meaningful business insights and provides an interactive view of shipping and delivery performance.

---

## 🎯 Business Objective

The main objective of this project was to analyze global logistics performance and provide a clear overview of shipping efficiency, delivery performance, and associated costs.

The analysis focuses on:

* Monitoring shipping performance
* Analyzing delivery metrics
* Evaluating logistics costs
* Comparing performance across countries
* Identifying shipping trends
* Analyzing delivery efficiency
* Providing an interactive logistics reporting experience

## 🔍 Analysis Performed

### Shipping Performance

Analyzed shipping activity and performance to understand overall logistics operations.

### Delivery Analysis

Analyzed delivery metrics to evaluate delivery performance and identify patterns in delivery times.

### Cost Analysis

Analyzed logistics and shipping costs to understand cost distribution and compare costs across different countries.

### Country Performance

Compared shipping and delivery performance across multiple countries to identify differences in logistics performance.

### Delivery Efficiency

Analyzed delivery-related metrics to evaluate logistics efficiency and identify areas for improvement.

### Trend Analysis

Analyzed shipping and delivery trends to monitor changes in logistics performance over time.

### Interactive Dashboard

Created an interactive Excel dashboard using visualizations and filters to allow users to explore logistics data from different perspectives.
